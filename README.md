# 拍摄清单样本库

这个仓库用于存放单人拍摄相关的脚本说明、拍摄清单和补拍素材清单样本。

## 当前样本

| 文件 | 用途 |
|---|---|
| `原始文件/单人拍摄内容.docx` | 原始 Word 文件，适合同事直接打开查看。 |
| `原始文件/单人拍摄的补拍画面.docx` | 原始 Word 文件，适合同事直接打开查看。 |
| `整理版/单人拍摄内容说明.md` | 从 Word 提取出的 GitHub 可预览版本。 |
| `整理版/单人拍摄补拍画面清单.md` | 从 Word 提取出的 GitHub 可预览版本。 |

## 使用建议

1. 给同事直接发文件时，优先使用 `原始文件` 里的 `.docx`。
2. 在 GitHub 上查看和维护时，使用 `整理版` 里的 `.md`。
3. 后续新增拍摄清单时，建议同时保留原始 Word 和整理版，方便协作与版本管理。

## 内容说明

- `单人拍摄内容`：单人讲解系列脚本说明，包含厨房、多功能房、客餐厅等内容方向，以及钩子设计。
- `单人拍摄补拍画面清单`：六支短视频剪辑所需的无人空镜、材质细节、动作瞬间、氛围空镜等补拍素材清单。
