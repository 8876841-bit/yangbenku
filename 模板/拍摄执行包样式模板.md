# 拍摄执行包样式模板

> 用途：以后每一个案例的拍摄执行包，都可以复制本模板，再按项目内容填充。
> 适用对象：家装案例、空间改造、探家、单人讲解、长视频带看、短视频矩阵拍摄。

---

## 0. 使用规则

1. 先写最终脚本，再写执行包；不要一边想内容一边写拍摄清单。
2. 执行包必须解决三个问题：现场拍什么、怎么拍、离场前检查什么。
3. 每个案例至少保留两个版本：
   - `最终脚本完整版本`：只放台词、平台版本、QC（质量检查）说明。
   - `拍摄执行包`：把脚本拆成镜头、动作、补拍、照片、现场顺序。
4. GitHub 里建议同时保留：
   - `.md` 版本：方便预览、复制、版本管理。
   - `.docx` 版本：方便发给同事、摄影师、现场执行人员。

## 7. 现场拍摄顺序模板

1. 进场前：确认光线、收拾杂物、清洁镜面、确认业主是否可轻出镜。
2. 先拍全屋动线：玄关 → 厨房 → 餐厅 → 卫浴 → 卧室 → 阳台。
3. 再拍短视频核心动作：门开关、台面手摸、海绵垫塞入、窗口推近等。
4. 再拍无人补镜：空间全景、材质细节、氛围空镜。
5. 最后拍照片：封面图、全景图、细节图、对比图。
6. 离场前现场回看，不要回家才发现漏拍。

## 11. 不可破坏的原则

1. 不夸大设计归属。
2. 不为了流量牺牲事实准确性。
3. 不只拍好看的画面，必须拍能剪成内容的画面。
4. 每个空间至少要有：全景、动作、细节、氛围、照片五类素材。
5. 执行包不是写给自己看的，是写给现场执行的人看的。
